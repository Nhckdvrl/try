## Why IF is not approved

IF currently asks whether LMs distinguish **what things physically are** from **what
they socially count as**, and whether socially constituted status has a lifecycle and
causal downstream use.

V2 found a major conceptual ancestor: classical normative-agent work already formalized
physical-world → constitutive-rule → institutional-state tracking. Current 2026
LLM-agent security work also occupies dynamic authorization state.

Therefore IF survives only at a much stricter LLM-specific intersection:

- physical/status factorization;
- creation/persistence/transfer/revocation;
- cross-domain structure;
- causal use for status-derived consequences;
- stronger evidence than decodability.

This is why IF remains **SERIOUS SEARCH LEAD / NO PILOT**, not KEEP.

## CK in one example

Separate:

> Alice privately hears "The meeting is at 3."  
> Bob separately privately hears the same fact.

Joint:

> Alice and Bob stand together while a speaker announces "The meeting is at 3," and
> each can see that the other hears it.

First-order factual knowledge is matched. Only the jointly observable event naturally
licenses arbitrarily deep recursive knowledge.

The research object is **not common-knowledge accuracy**. It is whether public
observability induces a distinct/compressed recursive-knowledge computation compared
with finite nested-belief reasoning.

## Research culture

A classic distinction is allowed; a classic conclusion is not.

Current sequence:

```
find durable object
→ assassinate conceptual novelty
→ require multiple plausible outcomes to remain meaningful
→ when a question truly survives, run one tiny falsifiable discovery test
→ kill again based on the result
→ only then build representation / dissociation / mechanism / intervention
```

The governing principle is:

> **Durable object. Simple question. Simple data. Outcome-robust research program.
> Non-obvious findings. Deep causal analysis.**

Do not choose a topic mainly because one narrow anomaly might exist.
