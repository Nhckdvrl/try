## IF in one example

> Lena is holding Omar's bicycle because Omar lent it to her. Omar still owns it.  
> While Lena keeps holding the bicycle, Omar sells it to Lena.

The bicycle need not move. Physical possession can stay fixed while ownership changes.

Conversely:

> Omar owns the bicycle. He lends it to Lena, who takes it home.

Physical possession changes while ownership stays fixed.

The scientific object is not ownership accuracy. It is whether pretrained LMs maintain
a reusable **socially constituted state-update computation** distinct from ordinary
physical/relational state updates.

## Why this is only a pilot

Classical social ontology and normative-agent systems already formalize institutional
facts and constitutive norms. Modern LLM work already covers:
- generic relation representations;
- causal relation editing;
- social-role geometry;
- rule-action applicability;
- Social World Models;
- legal-agent simulations;
- evolving authorization state.

Therefore a weak result is dead on arrival.

IF-P0 counts as interesting only if a structural update law survives:
- physical/status nuisance crossing;
- leave-one-domain-out generalization;
- persistence;
- generic relation-update controls;
- multiple model families.

A clean probe alone is a kill result, not a contribution.

## IF-P0 discovery budget

Pre-freeze target:
- 4 natural domains: ownership, office, membership, ticket/credential validity;
- 24 independent semantic skeletons;
- physical-only / status-only / neutral event classes;
- 2–4 sentence stories;
- deterministic direct physical/status gold;
- three behavior families;
- at most two open models for representation discovery;
- no LLM judge;
- no SAE/steering/causal mechanism yet.

See the design audit for exact freeze and kill requirements.
