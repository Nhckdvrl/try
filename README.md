## Why IF-P0 is suspended

IF remains a serious durable object:

> Lena is holding Omar's bicycle because Omar lent it to her. Omar still owns it.
> While Lena keeps holding the bicycle, Omar sells it to Lena.

Physical possession can remain fixed while institutional ownership changes.

However, V4 identifies two load-bearing problems in the V3 promotion.

First, V3's P4 case relied too much on an **exact joint intersection**: no located LLM
paper simultaneously covered physical/status factorization, status-only update,
persistence, transfer/revocation, cross-domain internal structure, generic-relation
controls and downstream use. That is not enough under this project's conceptual-novelty
standard.

Second, the current IF-P0 generic controls (e.g. location / possession / adjacency) are
not matched to the abstract/social character of the IF domains. A shared IF update
could therefore be generic **abstract/social relation updating** rather than a distinct
institutional-state computation.

Do not repair this by building a control zoo. IF can return to SMALL PILOT only if one
simple natural contrast directly defeats that reviewer compression.

## New serious challenger: CCD

The strongest new independent lead asks:

> **Does the model distinguish what caused something to become that way from what makes
> it the kind/state it is?**

Example:

> The glass is cracked because it fell.  
> The figure is a triangle because it has three sides.

The object is **dependency type**: causal/diachronic versus constitutive/synchronous
dependence.

CCD is not approved. Existing causal-reasoning, definitional-semantics, discourse-relation
and philosophical constitution work are real threats. A probe that separates the two
sentence types is trivial. CCD survives only if dependency type predicts a non-obvious,
cross-domain dynamic/counterfactual law that generic relation classification does not.

See V4 for the full Candidate Card, reviewer kill sentence and kill criteria.

## Why the search is still open

Current ranking is not a commitment to write either CCD or IF.

The project still requires:
- conceptual novelty assassination;
- a memorable structural law, not exact-condition novelty;
- outcome robustness;
- simple/direct data;
- success stronger than decodability;
- explicit kill criteria.

No GPU should be spent on CCD or IF until those gates are passed.
