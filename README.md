## Current serious question — IFG

> **Does an LLM weight the very same evidence differently depending on whether it is asked what is true now or what will happen next?**

IFG survives only at a narrow structural axis:

- same DGP;
- same prior;
- same realized signal;
- paired inference / forecast target;
- exact inference→forecast bridge through the DGP / Law of Iterated Expectations;
- evidence-weighting direction as the estimand.

A source-level BayesBench audit found a stronger collision than V12 initially recorded: BayesBench directly elicits latent-type posteriors and downstream predictions from the same rating history and tests conditioning/marginalization. Therefore IFG **cannot** claim generic inference–prediction inconsistency or “knows but cannot use.”

Its surviving claim is only:

> **changing only the requested target statistic may select a different evidence-processing computation despite an exact normative mapping between the two readouts.**

Still not approved. Still no pilot.

## V14 methodology correction

The search now explicitly prioritizes **durable old problems whose load-bearing assumptions change in the LLM era**.

Two additional questions are mandatory:

> **What exact old assumption no longer holds?**

and

> **If model names, APIs, prompts and agent frameworks change in two years, does the research question still matter?**

High-level positive identities include:
- **classical-law reassessment**;
- **cost/primitive shift**;
- **previously-unmeasurable → newly measurable**.

Default KILL:
> old task + GPT.

Potentially strong:
> old assumption + new model capability + changed scientific prediction / optimal method / measurement.
