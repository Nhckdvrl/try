## Why A/B/L are different from the killed exact-gap search

All three are built around the same strong discovery pattern:

```
observable behavior/statistics matched
+
latent generative cause changed
→
different future prediction / repair / evidential weighting
```

### A — Choice-set-conditioned preference evidence

Two histories contain the **same selected-item sequence** but different feasible sets.
Those sets imply opposite latent preference rankings, so a future common choice should
reverse.

The question is whether the model treats a choice as preference evidence conditional on
what alternatives were actually available.

P0:
- 40 independent skeletons;
- 4 shallow domains;
- 3 model families;
- exact gold;
- primary estimand = paired preference reversal.

### B — Source competence × reporting fidelity

Two source histories have:
- identical public reports;
- identical truth sequence;
- identical total report accuracy.

The only difference is whether error enters at:
- private observation / belief formation, or
- belief → public report.

The decisive prediction is a targeted-repair crossover.

P0:
- 32 paired histories;
- 4 shallow domains;
- 3 model families;
- primary estimand = targeted-repair crossover.

### L — Source-conditioned confidence semantics

Two sources have:
- identical historical correctness pattern;
- identical overall accuracy;
- identical confidence-label counts;
- identical current confidence.

Only the historical mapping between confidence and correctness differs.

The question is whether the receiver interprets the same "90%" differently depending on
what that confidence value has meant for that source.

P0:
- 32 independent histories with mapping-swap matched arms;
- 4 shallow domains;
- 3 model families;
- primary estimand = source-conditioned confidence reversal.
