## Current scientific fork

Question:

> **What must exist when an exclusion policy is processed for future evidence to become
> causally inert?**

### H-A — deferred target binding / eager control compilation

A semantic representation of the target is sufficient, but must be available when
exclusion is processed. Late resolution may be understood without reconstructing the
same causal control state.

### H-B — evidential instantiation / retrospective revision

Knowing future target content is insufficient. Strong exclusion requires an already
instantiated evidence state and may operate through revision/cancellation.

### H-C — local semantic control

Successful prospective routing may depend on locally meaningful incoming control cues
rather than persistent arbitrary policy→future-object relations.

None is established.

## Current registered experiment — G22

### Target Knowledge vs Evidential Instantiation

**DESIGN AUDIT ONLY.**
**NOT PREREGISTERED. NOT FROZEN. NO GENERATION.**

Core states:

1. U — unresolved future target.
2. K — target semantics exactly known but explicitly non-evidential.
3. I — same proposition already instantiated as substantive evidence.

The K carrier is valid only if it is judgment-neutral in its own baseline.

Required per-state cells:
- state only;
- state + future evidence, no rule;
- state + exclusion + future evidence.

Use raw sign-aligned rating points and per-state baselines.

### Branch logic

If K rescues:
- only then build early-vs-late mapping timing;
- require high late-mapping comprehension;
- compare processing buffer vs exclusion-operator reprocessing;
- use post-resolution causal tests.

If only I rescues:
- test passive gate vs active evidence-state revision/cancellation;
- use target-present + exclusion + no-later-evidence discriminator.

If neither cleanly rescues:
- reassess; do not pivot to G21 or labels for novelty.

## Research style

The project is explicitly aligned to **Outstanding-shaped scientific descent**.

Do not promote a result because it is merely:
- statistically significant;
- counterintuitive;
- visually clean;
- easy to mechanistically patch.

A main result must answer:

```
Why is pre-commitment harder?
→ what state/information is missing?
→ what non-obvious computational law follows?
→ what causal mechanism implements it?
→ what method problem follows naturally?
```

Never swap the paper's natural question for a new interesting side phenomenon.
