# Paper-scale audit — Unring the Bell

**Date:** 2026-09-23  
**Purpose:** recalibrate the reopened Unring line against recent ACL / EMNLP / NAACL Main papers and Sasano's actual paper-selection and writing comments.

This corrects the earlier over-optimistic conclusion that “G23C-R then write” would by itself make the project paper-complete.

---

# 1. Bottom line

The current project has a potentially Main-level **mother question** and several strong results, but the paper is **not yet experimentally complete**.

The problem is not raw GPU count. It is paper structure:

> a Main paper needs several clearly motivated research questions / findings that are individually convincing and collectively answer one natural mother question.

For this project the target is **three main RQs / three main findings**, with each finding owning a substantial experiment section.

G23C-R is useful, but it only strengthens RQ3. It does not make RQ1 and RQ2 paper-complete.

---

# 2. Sasano calibration

Recent Sasano Slack comments imply four hard requirements.

1. Reviewers will not excavate the interesting point from a complicated project. The paper itself must make the interesting point immediately understandable.
2. Surprise matters. A technically valid but obvious result is weak as a headline.
3. RQ and finding should map one-to-one. Introduction contribution bullets should map naturally onto the main experiment sections.
4. Main results must live in the main paper, not be rescued by a long appendix.

For Unring this means:

RQ1 -> Finding 1 -> behavioral/generalization section  
RQ2 -> Finding 2 -> structural-boundary section  
RQ3 -> Finding 3 -> causal-mechanism section

# 4. Mother question and scope

The paper should **not** be framed around “zero-amplified policy-state interchange.” That is too narrow and reads like an artifact of our experimental path.

The durable mother question remains:

> **Can language models commit in advance to ignore evidence they have not yet seen?**

More computationally:

> **When a policy is specified before future information arrives, can an LLM make that information causally irrelevant to a later decision?**

This is broad enough to connect instruction following, evidence use, retrieval/tool outputs, information-flow policies, selective forgetting/unlearning, and mechanistic contextualization.

The zero result is a finding inside that question, not the question itself.

---

# 5. Novelty compression test

## “This is just instruction position / recency.”

What must defeat the compression:
- matched Admit/order control;
- delay does not selectively worsen the prospective arm;
- eight wording families preserve the temporal asymmetry;
- masked-diffusion models preserve it;
- policy access can remain correct;
- exact prospective zero is executable in an explicit verifiable task;
- G23A shows an additional zero-instruction penalty.

## “This is just forgetting / unlearning.”

Our object is different:
> information can remain readable, true and recallable; the policy controls whether it may causally contribute to another decision.

## “This is just contextualization / a race condition.”

Our distinct object must be:
> a policy must become executable for a future semantic target, and complete exclusion incurs a distinct prospective cost.

The mechanism section must show a **policy-specific** causal state, not merely another mid-layer timing phenomenon.

## “This is just a function vector.”

Novelty cannot be “we patch a hidden state and behavior changes.”

It has to be:
> **the causal efficacy/content of a future-evidence policy state depends on whether its semantic target is available while the policy is processed.**

# 5A. Hard veto — reviewer-obvious / treatment-contains-the-answer experiments

The project has one canonical negative example: **G18 semantic targeting**.

G18's `para/entail` preview placed essentially the same proposition as the later
evidence into context before the rule. The later evidence's no-rule marginal then
collapsed from roughly 32 rating points to roughly 3.

The numerical result was real, but the original headline interpretation was not a
novel scientific law. A reviewer can compress the manipulation to:

> “You told the model the evidence content earlier; unsurprisingly the later duplicate
> evidence no longer changes the judgment much.”

That is a **triviality failure**, even if the experiment is preregistered, statistically
clean, and the effect is large.

Therefore every future headline experiment must pass all of these gates before compute:

1. **Treatment-does-not-contain-the-answer.** The manipulation may not directly supply
   the very semantic content, label, solution, or state whose later availability is the
   claimed explanation.
2. **Reviewer one-line test.** If the claim compresses to “give X, then X matters”,
   “repeat X, then the repetition matters less”, or an equally obvious consequence of
   prompt semantics, it cannot be a paper-center claim.
3. **Two live accounts.** Before generation, there must be at least two plausible
   explanations that make meaningfully different predictions under the *same* visible
   task content. Merely adding/removing an explicit cue is not enough.
4. **Unexpected result requirement.** The headline must contain something a reasonable
   reviewer would not predict from the manipulation alone. A large effect size does not
   substitute for surprise.
5. **No rescue by mechanism jargon.** Activation patching or hidden-state language does
   not make an obvious behavioral manipulation novel. The behavioral object must be
   non-trivial first.

Current interpretation of G18:
- valid diagnostic/provenance;
- useful frozen materials;
- evidence that prior semantic instantiation changes later control;
- **not** a standalone novelty-bearing law.

G20 was not the offending executed experiment; it remained design provenance and was
never run as a paper-center result.

# 7. Required paper architecture

## RQ1 — Does prospective evidence exclusion fail broadly and outside the authored vignette setup?

**Finding 1 target**

> The same evidence-exclusion policy is systematically less effective when committed before the evidence arrives, across models, architectures and evidence settings; the effect is not explained by generic instruction position or memory decay.

Main evidence:
- G0 breadth;
- wording/delay/diffusion controls;
- Stage-4A system-to-tool setting;
- **NEW G24A natural-evidence confirmation**.

### G24A — required new experiment

Use existing human/source-grounded evidence datasets rather than author-created stories.

Primary candidates:
- FEVER: Wikipedia claim verification with verified labels/evidence;
- SciFact: expert-written scientific claims with annotated supporting/refuting evidence.

Design goal:
- claim/background gives a base judgment;
- one annotated evidence block has measurable Admit leverage;
- the same zero-use rule is placed PRE vs POST relative to that evidence;
- independent SUPPORT/REFUTE labels remain available;
- selection uses only Base/Admit, never Exclude outcomes;
- 4–5 frozen models;
- several hundred items across the two datasets.

This is the immediate highest-priority design task.

---

## RQ2 — What is structurally special about the failure?

**RQ**

> Is prospective failure a general inability to remember/apply future numerical rules, or is complete semantic evidence exclusion a distinct control problem?

**Finding 2 target**

> Semantic evidence exhibits an extra prospective cost at the zero-use instruction, even though the same models can remember the requested policy and can prospectively execute exact zero when the contribution is explicit and verifiable.

Main evidence:
- G23A fresh zero-amplification;
- exact linear weighting control;
- policy-access/enforcement probes;
- source-grounded numeric invalidation as a boundary.

Do not say:
> “non-zero semantic weights are correctly implemented.”

G23A does not identify that.

No new compute is automatically required here until the Section-5 draft is written and audited for reviewer compression.

---

## RQ3 — What computation makes prospective exclusion executable?

**RQ**

> What rule-time state enables a policy to control evidence that has not yet arrived?

**Finding 3 target**

Conservative current form:

> the causal efficacy of a rule-time zero-vs-full policy state is target-conditioned.

Main evidence:
- Stage 5 target-state interchange;
- G23C policy-value interchange.

Required confirmatory additions:

### G23C-R — fresh-material replication
Keep the existing draft:
- frozen G18 legal + evidence-inference materials;
- 70 items / 20 disjoint skeletons;
- same models/site/layers;
- exact replication, no layer search.

### G24B — donor-state vs recipient-context factorization

Purpose: separate two explanations of G23C:

A. donor rule-end state itself carries target-conditioned policy information  
B. the state is generic, but matched recipient context is simply more sensitive to it

Minimal intervention:
- keep one recipient prompt fixed;
- patch rule-end states from M0/M100/U0/U100;
- compare the donor policy contrast M100-minus-M0 against U100-minus-U0 inside the same recipient;
- repeat for matched and unrelated recipients;
- L14 primary, L4/L24 controls;
- same two models and frozen items;
- no layer/site search.

A positive donor-side target-by-policy interaction with the recipient fixed is much stronger evidence that target availability changes what policy information is present in the rule-time state, rather than merely changing downstream susceptibility.

This should be prospectively frozen as a new causal test.

# 8. What does NOT count as extra paper thickness

Do not inflate the paper with:
- G23B carrier failure as a headline result;
- G18 as proof that semantic knowledge alone is sufficient;
- old G20/G21;
- every discovery-stage ladder;
- arbitrary additional models after seeing results;
- another broad prompt wording sweep;
- another layer search;
- another K-carrier;
- a mitigation method added only because the paper feels short.

G18 can appear as supporting evidence/motivation because it is a large frozen fresh round, but its semantic-preview interpretation is intrinsically mixed.

G23B is an honest identification failure and should be compact or appendix-level.

# 9. Required experiment volume before calling the paper complete

The target is not a fixed number of generations. The target is:

### Section 4 / RQ1
- broad original phenomenon;
- robustness controls;
- realistic agent setting;
- **one source-grounded natural-data confirmation**.

### Section 5 / RQ2
- fresh zero-amplification;
- explicit/verifiable prospective-zero boundary;
- policy-access/enforcement evidence.

### Section 6 / RQ3
- causal target-state localization;
- causal policy-state interchange;
- **donor-vs-recipient factorization**;
- **fresh-material replication**.

Only after those three sections are independently convincing should the project be called Main-paper complete.

# 10. Execution order

Do **not** run G23C-R immediately.

Correct order:

1. Freeze the three-RQ paper architecture.
2. Design G24A natural-evidence confirmation.
3. Novelty/data audit G24A before generation.
4. Run G24A if clean.
5. Design and freeze G24B donor-vs-recipient factorization.
6. Run G24B.
7. Finalize/freeze G23C-R and run the fresh replication.
8. Write complete Sections 4/5/6.
9. Only then decide whether RQ2 needs one extra confirmatory symbolic round.

G23C-R remains useful, but it is no longer the sole next step.

---

# 11. Stop discipline

More experiments are justified only when they fill one of the three named RQ gaps.

No “paper looks thin, add another ablation” behavior.

After G24A, G24B and G23C-R, the default is **WRITE**, not invent G24C/G25.

If one fails, update the corresponding finding's scope rather than creating an unbounded rescue chain.
