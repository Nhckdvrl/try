# Original preregistrations

This folder contains the **original experiment preregistration documents**, moved here without rewriting their historical contents.

Use [`../EXPERIMENTS.md`](../EXPERIMENTS.md) for the compact scientific overview. Come here when you need the exact frozen design: hypotheses, estimands, thresholds, qualification gates, sampling rules, planned analyses, or the chronology of a particular round.

The files intentionally preserve the language used at the time each experiment was designed. A later result may have overturned the motivating interpretation; that is scientific history, not an inconsistency to edit away.
